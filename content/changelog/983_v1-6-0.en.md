## Added
- You can now use BOMnipotent to [generate CSAF documents](/client/manager/doc-management/csaf-gen/) from minimal input in TOML format.

## Changed
- Switched to different crate for handling database access, improving performance and reducing dependencies.

## Fixed
- Updating vulnerabilities was not possible if the vulnerability was already known and had source "NULL".
